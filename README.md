# 📄 PDF Studio - Toolkit & Converter

**PDF Studio** is a premium, 100% offline Android app for students and professionals. Merge, split, sign, protect, and compress PDFs. Convert images to PDF. All on your device — no cloud uploads, no accounts required.

## ✨ Features

- 🖼️ **Image to PDF:** Convert photos to PDFs instantly.
- 🧩 **Merge PDFs:** Combine multiple PDF files into one.
- ✂️ **Split PDF:** Extract specific pages from any PDF.
- ✍️ **Sign PDF:** Draw your signature and add it to any PDF.
- 🔒 **Protect PDF:** Password-protect sensitive documents.
- 🖼️ **PDF to Image:** Convert PDF pages to high-quality JPGs.
- 🗜️ **Compress PDF & Image:** Reduce file sizes without losing quality.
- 📝 **PDF Creator:** Type text and save as PDF.
- 🌙 **Premium Neon UI:** A beautiful glassmorphism dark theme.
- 💰 **Watermark + Rewarded Ads:** Watch an ad to remove watermark and support development.
- 🔒 **100% Offline:** All files stay on your device. No uploads.

## 🚀 Installation

1. Go to the **[Releases](https://github.com/CartonIQ/PDF-Studio/releases)** page.
2. Download the latest `PDFStudio-Signed.apk`.
3. Open and install (allow "Install from unknown sources" if prompted).

## 🛠️ Built With

- **Language:** Kotlin
- **UI:** Material 3, XML Layouts, ViewBinding
- **Architecture:** MVVM, Navigation Component
- **PDF Generation:** Android Native `PdfDocument`
- **PDF Editing:** Apache PDFBox Android
- **Local Database:** Room DB
- **Monetization:** Google AdMob (Banner, Rewarded, Interstitial)
